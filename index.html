roblox uri scheme

Turn a share link into a roblox:// call

Paste a roblox.com/share or share-links URL. It's parsed down to its code and type params, then rebuilt as the app's native navigation/share_links deep link.

Works with any link that carries code and type query params — private servers, VIP servers, or other share links. Shortened ro.blox.com links need to be expanded first (open once in a browser, then copy the resulting address-bar URL).
